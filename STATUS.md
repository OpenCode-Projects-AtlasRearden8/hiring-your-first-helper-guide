# STATUS.md — Hiring Your First Helper Guide

Last updated: 2026-11-05

## What was built

A complete, beginner-friendly small-business manual for hiring your first
contractor or part-timer — education only, never legal or tax advice — with a
static website generated from the markdown source.

**Content (in `docs/`, markdown):**

- `00-start-here.md` — how to use the guide, and the anti-overwhelm opening
- `01-should-you-hire.md` — what kind of help fits; the eliminate → automate →
  delegate ordering; contractor vs. employee in plain English
- `02-writing-the-posting.md` — honest posting anatomy, pay-in-posting rule,
  a full worked example
- `03-fair-trial-projects.md` — always-paid trial projects, what they signal,
  kind pass/reject templates
- `04-paying-people-plainly.md` — rate/flat/retainer/unit structures; the
  W-9 → invoice → 1099-NEC paperwork shape; an example payment log
- `05-records-you-keep.md` — the three-record system (person folder, payment
  log, shared folder) plus a plain-language working-agreement template
- `06-onboarding.md` — the three-stage no-flood onboarding rhythm, day-one
  email template
- `07-offboarding.md` — kind endings plus the same-day tool-access checklist
- `08-keeping-your-head-above-water.md` — a filter for the guidance firehose
- Extras: `interview-scorecard.md` (7-trait printable scorecard with decision
  cutoffs and interview questions), `first-week-onboarding-sheet.md`
  (fill-in Monday–Friday plan), `glossary.md` (plain-English definitions)

**Website (`site/`, generated by `build.py`):**

- `index.html` (table of contents) + 12 chapter/tool pages
- Top nav on every page, prev/next links between pages, dark-mode support,
  fully self-contained inline CSS, works from `file://` with no network calls

**Tooling:**

- `build.py` — converts `docs/*.md` to `site/*.html`; pure Python standard
  library, no dependencies, no network
- `test_build.py` — rebuilds the site from scratch and runs 100+ checks
  (pages exist, required content present, HTML sanity, cross-links, no
  external references, LICENSE/README credits)
- `LICENSE` — MIT, copyright line exactly `Copyright (c) 2026 Asdale Dynamics, LLC`
- `README.md` — overview, chapter map, how to run; credits Asdale Dynamics, LLC

## How to run it

```bash
python3 build.py        # regenerate site/ from docs/
python3 test_build.py   # build-from-scratch + full verification suite
```

Then open `site/index.html` in any browser. No server, no install, no network
needed. Requires only Python 3.8+.

Companion guides (referenced in the README, not included here):
`llc-first-year-handbook` and `freelance-first-client-guide`.

## Known gaps

- **Manual-ahead-of-professional boundary:** the guide deliberately explains
  US-ish contractor paperwork (W-9/invoice/1099-NEC) in outline only. State and
  country specifics, employee payroll, and edge-case misclassification tests
  are pointed at professionals rather than covered — by design.
- **No PDF/print stylesheet:** the extras are meant to be printed from the
  browser (Print → Save as PDF works via default browser styling), but a
  dedicated print CSS wasn't included.
- **Site search:** none. The TOC + nav is enough at 13 pages, but a local
  search index is a natural future addition.
- **Markdown parser scope:** `build.py` implements the markdown subset this
  project uses (headings, tables, fenced code, lists with checkboxes,
  blockquotes, inline styles). It is not a general Markdown implementation;
  deeply nested or exotic constructs may render as plain paragraphs.
- **Checkboxes aren't interactive** in the HTML (rendered as disabled inputs
  meant for print/screen use); form handling was intentionally out of scope.
- **`site/` is committed** alongside the source; run `python3 build.py` after
  editing docs to regenerate. (An alternative .gitignore approach could
  exclude it, but committing keeps the built site browsable out of the box.)
